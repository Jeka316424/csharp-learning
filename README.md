# Git з нуля: перші кроки (пройти ДО початку навчання C#)

## Про що тема
Git — система контролю версій: вона запамʼятовує історію змін твого коду і дає змогу відкотитися, експериментувати й показувати код іншим. **Весь навчальний код з цього плану треба вести через Git з першого дня** — так за кілька місяців ти отримаєш і навичку, і живий GitHub-профіль для роботодавця.

Акаунт на GitHub уже є — тепер треба зрозуміти, що взагалі відбувається, і виробити щоденну звичку.

## Ключові поняття простими словами
- **Репозиторій (repo)** — папка з проєктом, за якою Git стежить
- **Коміт (commit)** — "збережена точка" в історії: знімок твоїх змін з підписом
- **Staging (git add)** — "кошик": ти обираєш, які саме зміни увійдуть у наступний коміт
- **Remote (GitHub)** — копія репозиторію в хмарі; `push` — відправити свої коміти туди, `pull` — забрати звідти
- **Клонування (clone)** — скачати чужий/свій репозиторій собі на компʼютер
- **.gitignore** — список файлів, які Git має ігнорувати (для C#: папки `bin/`, `obj/`)

## Мінімальний набір команд (вивчити руками, не з памʼяті)
```bash
git init                  # почати стежити за папкою
git status                # ЩО зараз відбувається (найуживаніша команда!)
git add .                 # додати всі зміни в "кошик"
git commit -m "опис"      # зберегти точку в історії
git log --oneline         # подивитися історію
git clone <url>           # скачати репозиторій з GitHub
git push                  # відправити коміти на GitHub
git pull                  # забрати зміни з GitHub
```

## Порядок дій (покроково)
1. Встанови Git: https://git-scm.com/downloads (Windows — усе за замовчуванням)
2. Представся Git-у (один раз):
   ```bash
   git config --global user.name "Імʼя Прізвище"
   git config --global user.email "email-як-на-GitHub"
   ```
3. Створи на GitHub репозиторій `csharp-learning`, клонуй його собі — і складай туди ВЕСЬ код із наступних папок цього плану
4. Вироби звичку: закінчив заняття → `git add .` → `git commit -m "що зробив"` → `git push`
5. Додай у корінь репозиторію `.gitignore` для C#: на GitHub при створенні repo обери шаблон "VisualStudio", або скопіюй звідси: https://github.com/github/gitignore/blob/main/VisualStudio.gitignore

## Що поки НЕ треба
Гілки, merge, rebase, конфлікти, Pull Request-и — це все буде в темі `04-Професійний/04-Git-і-інструменти`. Зараз достатньо лінійної історії: add → commit → push. Не намагайся вивчити весь Git одразу — 8 команд вище покривають 90% щоденної роботи.
